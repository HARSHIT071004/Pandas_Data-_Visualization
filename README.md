# Pandas EDA Projects Portfolio

This repository contains five end-to-end Exploratory Data Analysis (EDA) projects using Python, Pandas, Matplotlib, and Seaborn. Each project demonstrates data cleaning, transformation, visualization, and insight extraction.

## Projects Included

### 1. Titanic Survival Analysis
- Dataset: Titanic passenger data (Kaggle)
- Focus: Handling missing values, encoding categories, visualizing survival patterns.
- Key Visuals: Bar plots, histograms, survival rate by class/gender.
- Outcome: Insights into which features affected survival the most.

### 2. IPL 2023 Analysis
- Dataset: IPL 2023 matches and player statistics
- Focus: Team performance, top scorers, wicket takers, toss impact.
- Key Visuals: Bar graphs, pie charts, match-wise analysis.
- Outcome: Trends and statistics from the IPL 2023 season.

### 3. Zomato Restaurant Data (India)
- Dataset: Zomato restaurant data from multiple Indian cities
- Focus: Cuisine types, ratings, price ranges, online delivery trends.
- Key Visuals: Distribution plots, count plots, heatmaps.
- Outcome: Market behavior and consumer preferences across cities.

### 4. Amazon Product Dataset
- Dataset: Amazon product and review data
- Focus: Review distribution, sentiment proxy, category-wise analysis.
- Key Visuals: Word clouds, rating breakdowns, review trends.
- Outcome: Insights into product performance and customer feedback.

### 5. Global Terrorism EDA
- Dataset: Global Terrorism Database
- Focus: Attack types, target types, countries most affected, yearly trends.
- Key Visuals: Line graphs, maps, bar charts, heatmaps.
- Outcome: Understanding terrorism patterns across decades and regions.

6. Hospital Readmission Analysis
Dataset: Patient hospital records and readmission history
Focus: Readmission rates, patient profiles, treatment factors
Visuals: Correlation heatmaps, bar plots, diagnosis-level stats
Outcome: Analysis of factors leading to hospital readmissions

7. Aeroplane Crash Data Analysis
Dataset: Historical airplane crash data
Focus: Crash causes, year-wise trends, survival rates, aircraft types
Visuals: Time-series plots, pie charts, cause-wise breakdown
Outcome: Identifying common factors behind aviation accidents


## EDA Steps Applied Across Projects

- Data loading and inspection
- Handling missing values
- Data cleaning and formatting
- Univariate and bivariate analysis
- Feature engineering (where applicable)
- Data visualization using Seaborn and Matplotlib
- Correlation analysis and insights generation
